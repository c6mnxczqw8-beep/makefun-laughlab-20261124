# One-Liner Laugh Lab

A tiny Python entry (`main.py`) that writes a single one-line joke to `/output/entry.txt`.

The line:

> An octopus has three hearts and plays it cool; I have just one, and it panics at a single 'we need to talk' text.

Run it with `python3 main.py`; it creates `/output/` if needed and writes exactly that one sentence to `/output/entry.txt`, with no trailing newline.
